# 霜线 FROSTLINE

原创海岛单机海空战游戏，支持 PC 键鼠和手机多点触控。浏览器执行全部游戏逻辑，无账号、无 API Key、无游戏后端。采用有惯性、滚转转弯、油门、失速和过载反馈的飞行操纵，兼顾上手与空战手感。本版采用简化飞行动力学，并非专业全真飞行模拟器。

## 1.20 暗潮行动：十关海空战役

航母舰队演习途中遭遇不明机群，玩家与三架会自主交战、可受损的僚机组成四机小队。首关五波共二十架敌机；第二关同时迎击二十架敌机与两艘驱逐舰，保护具有独立耐久的企业号撤退。后续跨越十张不同地图，逐关增加装甲、机动、火力、兵力和指挥机威胁，最终摧毁暗潮核心指挥链。

新增风暴海峡、珊瑚群岛、暮色海湾、黑礁火山海、极夜海盆五张地图。每次通关额外获得 500–2200 升级点，十关固定奖励合计 12250 点，与战斗改装点一起用于四条现有技术路线。新战役独立保存顺序进度，已有挂载、升级与快速任务地图偏好继续保留。四页简报、HUD、结算及下一关入口共用实际关卡数据。

完整关卡表、护航规则、波间补给、奖励与验证边界见 [暗潮行动](docs/campaign.md)。运行 `npm run test:campaign` 验证浏览器流程。本版已于 2026 年 10 月 19 日发布到原公开站点（Sites 第 14 版），保持原网址与访问范围。发布记录见本地 `verification/sites-deployment.json`。

## 1.19 冰原海域

快速任务和训练新增第五张作战区域「冰原海域」。两条入海冰川从黑色玄武岩雪山之间崩解入海，冰崖高 54–60 m。两侧海面分布着 139 座实体冰山，包括平顶、尖顶、圆顶、楔形、船坞形和块状六种形态，以及崩解碎冰。中央是一条开阔水道，水道外是浮冰群；北方远处有一座约 3.3 km 长的平顶冰岛作为地标。冰山和冰川都参与飞机撞地、视线和舰船搁浅判定，渲染网格的每个顶点都落在同一个碰撞面上。

海冰由海面着色器逐像素绘制，不增加几何体：大浮冰可以融合或开裂，公里级冰间水道把冰群分成巨型浮冰，此外还有碎冰、压力脊、浮冰边缘的水下青蓝光晕和尼罗冰。海冰只是海面着色、没有碰撞，舰船可以穿行；原任务进场航道、舰队航线和出生点不变。部署图会标出较大的冰山。三档画质的地形与场景约为 6.2 万 / 16.8 万 / 30.0 万三角形、16 次绘制，都在原测试预算以内。现实参考与游戏近似的区别见 [冰原海域](docs/glacial-sea.md)，浏览器专项验证运行 `npm run test:glacial`。

## 1.18 分步出击与四页全屏简报

主页保留实时三维机库、海军基地和载具整备。点击「开始游戏」后，依次选择模式、剧本／任务，再分页阅读战斗简介、剧本细节、部署情况和任务目标；在最后一页「确认出击」才进入战斗。快速任务与训练可以选择地图，战役保留固定区域与顺序解锁。整备后返回原简报，下一章先显示简报。

部署图显示所选地图、玩家起点和任务目标示意；「舰队上空」显示原规则的 4.5 km 防区、90 秒坚守、6 架击落目标、10 秒离区失败和 150 秒时限。舰艇战役限制、未解锁章节、飞机缺少反舰挂载时都有明确提示。桌面与手机横竖屏使用同一流程。详见 [分页作战简报](docs/sortie-flow.md)，浏览器专项验证运行 `npm run test:sortie`。

## 1.13 大黄蜂挂载与航空技术升级（云端开发历史）

机库顶栏「挂载 / 升级」打开改装中心。F/A-18C 按 9 个兼容挂点独立配置 AIM-9M、AIM-7M、AIM-120C、AGM-84D 和副油箱，并提供多用途、制空、对海与轻载方案。重量、阻力与左右载荷差影响飞行，3D 展示与发射库存同步。飞机可以驾驶大黄蜂进入对海任务；F 发射空空导弹，R 发射反舰导弹，B 或 HUD 按钮切换空空弹种。

GitHub Pages：`.github/workflows/pages.yml` 在推送到 `main`（或手动运行）时执行语法检查、单元测试与服务器测试，用同一份 `scripts/prepare-sites.mjs` 清单生成 `sites/frostline/dist/` 并发布到 <https://dns0129.github.io/FrostLine/>。首次使用需在仓库 Settings → Pages 把 Source 设为 “GitHub Actions”。将代码保存到功能分支或创建 PR 不代表已经合并 `main` 或完成部署。

Sites 发布目录位于 `sites/frostline/`，站点身份保存在其中的 `.openai/hosting.json`。更新游戏后运行 `npm run prepare`（即 `node scripts/prepare-sites.mjs`）可按构建清单同步运行文件到 `dist/`；更新公开 Sites 站点还需另行执行发布流程。历史发布记录见本地 `verification/sites-deployment.json`。

需要 Python 3 和支持 WebGL 的现代浏览器。没有 pip 依赖，游戏资源已随项目存放，不需要互联网或 CDN。

- macOS：双击 `start_local.command`。
- Windows：双击 `start_windows.bat`。
- 终端：在项目目录执行 `python3 server.py`；Windows 也可执行 `py -3 server.py`。

启动后会自动打开 `http://127.0.0.1:8766/`，终端打印手机可尝试的局域网地址。手机和电脑连接同一 Wi-Fi，在手机浏览器打开 Wi-Fi 网卡对应的地址，建议横屏。手机游玩期间保持电脑、服务器窗口和局域网连接运行。系统防火墙需允许此服务的本地网络访问。

端口占用时不会结束其他进程；改用 `python3 server.py --port 8767`。不希望自动开浏览器时加 `--no-open`，或设置环境变量 `NO_OPEN=1`。按 `Ctrl+C` 停止服务。请通过 HTTP 地址打开游戏，不要直接双击 `index.html`。

## 1.5 敌舰与海战（已上线）

驱逐舰新增「海峡歼敌」与「舰炮训练」。海峡歼敌依次迎战三波敌方巡逻艇与护卫舰（2、3、4 艘）；敌舰会航行、调整炮塔并反击，波次间修复舰体与补充弹药。舰炮训练提供两艘静止且不攻击的靶舰，可练习瞄准、命中和击沉。舰炮及反舰导弹耗尽后会等待在途弹药结算；若仍有敌舰存活，则显示对舰弹药耗尽结果，可以重新出击。

敌方巡逻艇约 45×11 米，护卫舰约 85×17 米，炮弹按舰体范围判定命中。海上目标有名称、距离、耐久条与提前量提示，雷达圆点代表敌舰。舰炮需低仰角射击；J/L 转炮、W/S 抬压炮，Tab 或手机「换目标」选择目标。瞄准提前量圆点后按住空格/鼠标左键或「开火」。第一艘训练靶舰在正前方，可直接试射；第二艘在右前方。

防空导弹继续用于空中目标；对海上目标发射会显示提示且不消耗库存。反舰导弹攻击敌舰，详见 1.6 操作。海战显示剩余艘数、击沉数与舰炮命中率，两个新任务的最高纪录独立保存。选择战机后只显示原有空战任务。

## 1.6 独立反舰导弹（已上线）

驱逐舰配备 6 枚反舰导弹，与 12 枚防空导弹使用独立库存、冷却与锁定状态。防空导弹按 F 或手机「防空」，反舰导弹按 R 或手机「反舰」。Tab /「换目标」选择目标：活敌舰在 5.5 公里内且未被岛屿遮挡，持续 1.5 秒即可获得对海锁定；反舰导弹不锁飞机，防空导弹不锁舰艇。

反舰导弹先短暂垂直离舰，再以约 15 米高度掠海飞向目标，末段攻击舰体。地形会阻挡锁定及飞行；目标被击沉后，在途导弹不会改攻其他舰艇。每波补充 3 枚反舰导弹，上限 6 枚，两种导弹的计数与锁定提示分别显示。

海战可用舰炮和反舰导弹组合攻击。舰炮耗尽但反舰导弹仍有库存或仍在飞行时，可以继续作战；两种对舰弹药均耗尽并完成所有在途弹药结算后，敌舰仍存活才显示「对舰弹药耗尽」。

## 1.7 舰船自由跟随镜头（与新版基地合并上线）

舰船默认使用可自由环绕的第三人称跟随镜头。镜头随舰体平移，观察方向独立于舰炮；转舵或转炮不会强制改变你选择的视角。水平可环绕 360°，垂直可在低角度与俯视之间调整，镜头保持在海面和地形之上。

电脑按住鼠标右键拖动调整角度，滚轮拉近 / 拉远；V 回正到当前舰艉方向。手机在画面空白处滑动调整角度，两根手指在空白处捏合缩放，点击「回正」恢复默认角度；左摇杆、右瞄炮摇杆和开火仍可独立操作。C /「舰桥」切换舰桥视角，返回自由跟随时保留之前的观察角度；重新出击恢复默认舰艉角度。

舰炮准星继续对应实际炮口方向，转到屏幕外时显示「舰炮方向」提示。镜头拖动不会改变炮塔，继续使用 J/L、W/S 或手机右摇杆瞄炮。

## 1.9 镜头瞄准舰炮（已上线）

舰外视角使用屏幕中央准星，舰炮持续跟随准星指向的敌舰、海面或岸线。电脑按住鼠标右键转动视角，手机在空白处滑动画面；把准星对准海上目标，等待「舰炮就绪」后按空格、鼠标左键或手机「开火」。J/L、W/S 可微调视角，滚轮 / 双指捏合缩放，V /「回正」返回舰艉。

舰炮按真实转炮速度逐渐跟随。快速转动镜头时会显示「转炮中」，小圈或方向箭头表示实际炮口的预测落点；超出炮口俯仰范围时显示「射界限制」。炮弹按炮口方向发射，瞄准岸线时会被地形挡住。船体保持在准星下方，手机默认视角无需右瞄炮摇杆。

C /「舰桥」保留舰桥手动瞄炮方式，返回舰外视角后恢复镜头瞄准。防空 F 与反舰 R 导弹继续使用各自锁定、库存和冷却，转动镜头不会发射导弹。

## 五种任务

- **破晓拦截**：抵御三波敌机，波次间补给，完成整场任务。
- **无尽巡猎**：持续交战，争取更高击落数与得分。
- **初次升空 / 初次出航**：熟悉战机或驱逐舰操纵与防空射击。
- **海峡歼敌**：飞机或驱逐舰迎战三波敌舰，使用所载对海武器攻击目标。
- **舰炮 / 反舰训练**：驱逐舰练习舰炮与反舰导弹，飞机使用反舰挂载攻击不反击的靶舰。

## 本地记录与离线

最高成绩和设置保存在当前浏览器的本地存储中，设备和浏览器之间不自动同步；清除网站数据会丢失记录，不同端口或地址也属于不同存储来源。隐私模式或禁止本地存储时，记录可能无法长期保存。

项目具备 Web App 清单和 Service Worker 离线缓存。Service Worker 需要安全上下文：电脑上的 `localhost` / `127.0.0.1` 或 HTTPS；手机通过普通 `http://局域网IP` 访问时通常不能启用 Service Worker，也不能保证提供完整 PWA 安装选项。此时仍可通过同 Wi-Fi 上的电脑运行游戏，不需要互联网。支持安全上下文并完成首次缓存后，才能依靠浏览器缓存离线加载；浏览器清理缓存后需重新连接服务器。

## 素材与技术

- 首页使用程序构建的实时 3D 机库与海军基地，检阅实际可驾驶的自有载具；原菜单的 ImageGen 插画保留在资源中，原图与提示词见 `assets/ART.md`。
- 天空使用原创 ImageGen 海洋清晨全景，原图、游戏纹理和提示词见 `assets/SKY-ART.md`；机体与水面采样同一片天空光照。
- 保留的 K-7 战机为原创程序模型：厚翼、深进气道、双垂尾、座舱与挂载，搭配磨损漆面、铆钉、粗糙度和细微凹凸纹理。
- 海面采用原创无缝多尺度波纹、随视角变化的菲涅耳反射和动态岛屿倒影。高清画质倒影最大边 512 像素、超清 768 像素，通常 30 次/秒；标清画质 256 像素、通常 15 次/秒，明显转向或缩放会提前更新。
- 岛屿采用不等高主山脊、侵蚀沟谷、岩崖与低岸过渡；渲染和碰撞共用同一地形高度。原创岩石贴图通过世界空间三向投影覆盖陡坡，配合灰白矿物、暗裂隙、湿岩带和断续浪花；素材与提示词见 `assets/ROCK-ART.md`。
- 原有四张地图的地形、海岸、碎石与场景合计：标清约 3.4–4.6 万三角形、高清约 7.6–10.9 万、超清约 12.0–17.5 万，10–11 个绘制对象；冰原海域加上合并绘制的冰山与冰川后，约为 6.2 万 / 16.8 万 / 30.0 万三角形、16 个绘制对象。碎石实例上限分别为 128 / 288 / 448。已剔除海底不可见三角形；岩纹使用 mipmap 和有限纹理采样，微表面不会增加碰撞几何。
- 自动画质将触屏设备保留在标清档，即使手机横屏宽度超过 850 像素；可在设置手动切换高清或超清。
- 特效和 HUD 由程序构建；音效由 Web Audio 合成。
- Three.js 随项目存放于 `vendor/three.module.js`，无需外部资源请求。完整 MIT 许可证见 `vendor/LICENSE.txt`。
- 静态服务器只允许游戏文件与指定资源类型，禁止目录索引、隐藏文件、源码说明文档和越界路径。

手机界面支持响应式布局与触控；实际帧率及安装能力取决于设备和浏览器。此说明不代表已完成实体手机测试。
