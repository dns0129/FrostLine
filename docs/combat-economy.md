# 1.22 武器商店、无限补充与双币成长

本版取代 1.21 的逐发弹药收费。玩家在机库永久购买导弹和机炮，局内弹药无限，消耗的是补充时间。所有数值是 FrostLine 游戏参数，三档武器是虚构的伤害等级，不代表现实武器的新型号。

## 机库购买

机库「武器 / 升级」内置武器商店；基地「武器商店」也可购买和装备。武器所有权、银币、金币、技术等级和经验共用浏览器存档，所有可驾驶飞机与舰船共享已购武器等级。

| 武器 | 等级 | 伤害倍率 | 永久购买价格 | 补充时间 |
| --- | --- | --- | --- | --- |
| 导弹 | M-I 基础 | ×1 | 免费拥有 | 空空 / 防空 5 秒，反舰 7.5 秒 |
| 导弹 | M-II 强化 | ×1.4 | 900 银币 | 空空 / 防空 7 秒，反舰 10.5 秒 |
| 导弹 | M-III 精锐 | ×2 | 120 金币 | 空空 / 防空 9 秒，反舰 13.5 秒 |
| 机炮 / 舰炮 | 标准 | ×1 | 免费拥有 | 打空当前弹匣后 3 秒补满 |
| 机炮 / 舰炮 | 穿甲 | ×1.4 | 600 银币 | 打空后 3.5 秒补满 |
| 机炮 / 舰炮 | 高爆 | ×2.2 | 80 金币 | 打空后 4 秒补满 |

购买时只扣款一次并自动装备，已拥有的武器不能重复购买。切换已购武器免费；余额不足的购买按钮显示所需货币与价格。局内不扣币，余额为零也不降档，尚未购买的等级不能装备。基础武器始终可用。

导弹等级同时作用于当前飞机的空空、反舰武器与舰船的防空、反舰武器；机炮等级同时作用于飞机机炮和舰炮。飞机仍使用各自的导弹外形、射程与制导：大黄蜂可循环 AIM-9M、AIM-7M、AIM-120C，反舰使用 AGM-84D；歼-16 可循环 PL-10、PL-15，反舰使用鹰击-83K。购买等级不改变目标类别和锁定规则。

## 局内补充

- 飞机当前机炮弹匣为 60 发，舰炮为 12 发。打空后自动进入表中的补充倒计时，完成后补满，可以反复补充，没有局内总弹药上限。
- 导弹每个发射系统就绪一枚；成功发射后进入补充倒计时，到期重新就绪。空空 / 防空与反舰使用独立计时，同一系统切换导弹型号仍共享当前计时。
- 补充期间禁止开火；机炮射速、热量、过热冷却、导弹锁定、舰船模块故障和并行防空通道限制仍生效。补充完成并不绕过损坏模块。
- 切换已购武器不会取消、重置或缩短已开始的补充计时；本次补充结束后，下次开火采用新武器的补充时间。暂停冻结所有计时。重开恢复当前弹匣和发射系统，保留已购武器、货币及技术。
- 波间补给重置武器补充计时并补满机炮弹匣，其他修复、燃油与诱饵奖励继续保留。训练可以使用已经购买的武器，训练仍不发货币或经验。

伯克级和 052D 的防空战备使防空补充缩短 20%、反舰补充增加 20%，诱饵少两组；反舰战备反向调整两类导弹补充时间。均衡战备与 D-21 使用表中的基础时间。

作战 HUD 显示当前机炮弹匣 / 无限储备，打空时显示补充倒计时；空空、防空和反舰按钮分别显示自己的补充倒计时。HUD 只循环已拥有的等级。

## 取消挂架

机库不再编辑挂点、外挂重量、左右平衡、预设挂载或有限导弹数量。旧挂载不会影响当前飞机的速度、机动、燃油和任务资格；所有飞机都可使用基础空空和反舰武器，没有因旧挂载缺失而无法出击的情况。

停机与飞行模型均移除外挂导弹、副油箱、挂架和发射导轨。F/A-18C 的挂架来自原材质分组；歼-16 的六个独立导轨 / 挂架和机翼网格中四个独立挂架组件全部从显示模型移除，保留主翼、机身、起落架和固定翼尖电子战吊舱。原 GLB 与许可证不修改，清洁显示几何体由资产所有者共享和释放。飞行中的导弹继续使用原真实比例模型。

武器从机体下方生成，是无限弹药玩法的内部发射近似，不代表现实飞机的内部弹舱。旧挂载解析器保留用于读取历史数据和模型参考，实际玩法不再使用挂点。

## 货币与存档

`frostline-workshop-v1` 保留原存档键，内容版本升至 3，新增 `ownedWeapons`。旧银币、金币、XP 与技术等级保留；旧 `credits` 按 1:1 转为银币并仅保留兼容镜像。1.21 存档当时选中的武器等级会免费迁移为永久拥有，基础武器始终拥有；迁移只发生一次，刷新不会重复赠币或退款。旧挂载只作历史兼容，不再参与出击。

新档仍有 1200 银币、25 金币。货币通过游玩获得，没有充值。浏览器本地存档不会自动跨设备、域名或浏览器同步。

飞机和舰船实战统一结算：银币 = 100 + 击杀 × 60 + min(500, floor(得分 / 20)) + 胜利额外 300 + 战役固定通关奖励；XP = 击杀 × 100 + 胜利额外 400。普通任务胜利获 8 金币，战役第 N 关获 10 + 2N 金币，无尽每完成三波在本局结算时获 2 金币。失败有击杀仍获得战斗银币和 XP，训练、无击杀失败和主动退出不发奖励；同一结果页只结算一次。

## 保留的战斗与成长规则

敌机分轻松、标准、王牌：从低提前量追击和短点射，逐渐加入预测拦截、侧翼包抄、导弹规避、热焰弹和小队目标分配。新波次至少在玩家 3.8 km 外入场，出生高度至少比地形高 500 m；入场有 4 秒加反应时间的攻击保护。存活敌机在边缘自行返航，不水平瞬移。训练靶机不攻击。

可交战单位基础血量保持 1.20 的两倍，玩家基础伤害保持降低 15%，再乘技术与武器倍率。大黄蜂 / 歼-16 为 200 / 250 HP，D-21 / 伯克 / 052D 为 600 / 840 / 780 HP，僚机 270 HP，第二和第七关航母 4400 / 4000 HP。敌方、僚机和独立近防炮保持原火力规则。

指挥官仍为 30 级，第 L 级累计 XP 门槛为 `(L−1)×400 + (L−1)×(L−2)×100`。四条航空技术各五档，要求指挥官 1 / 3 / 5 / 8 / 12 级，费用 300 / 700 / 1400 / 2400 / 3800 银币；从各机型基础值计算一次，全机型共享。

## 验证

`npm test` 覆盖永久购买和重复购买保护、存档迁移、五种载具实际导弹和机炮伤害、零余额使用、自动补充、独立计时、暂停与切换防绕过、波间补给、舰船战备效果，以及无挂架几何和资源生命周期。`npm run test:combat` 通过实际 WebGL 验证机库购买、装备、键盘发射、补充倒计时、刷新存档、升级和手机横竖屏；`test:campaign` 和 `test:sortie` 验证十关战役与出击流程。结果奖励与关卡完成部分使用受控战果夹具，不能等同于人工逐关通关。
