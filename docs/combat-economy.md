# 1.21 敌机 AI、弹药和双币成长

所有数值均为 FrostLine 的游戏平衡参数。弹药等级为虚构的伤害档位，沿用所挂载武器的外形、射程、制导和挂点兼容性，不代表现实武器型号。

## 敌机作战

| 难度 | 飞行和瞄准 | 防御与协同 |
| --- | --- | --- |
| 轻松 / 简单 | 较慢决策、较少提前量、短点射，近距交汇后脱离重整 | 不主动规避导弹，无热焰弹；同一目标最多同时承受一枚敌方空空导弹 |
| 标准 / 普通 | 预测拦截，部分飞机从侧翼包抄，增加点射密度 | 导弹接近 1.7 km 时转向规避，一组红外诱饵 |
| 王牌 / 困难 | 更快决策和转弯、更高提前量、更紧密点射，扩大侧翼距离 | 2.6 km 内规避来袭导弹，三组红外诱饵；小队战中优先选择较弱且较少被围攻的友方单位 |

诱饵会生成真实粒子并把来袭 AIM-9M / PL-10 引向诱饵点，不消除所有导弹；雷达弹仍按原引导规则飞行。规避和脱离期间停止攻击。敌机保留地形视线检查、前方地形爬升和近距分离。训练靶机始终无攻击性。

每波飞机从距离玩家至少 **3.8 km** 的水平距离进入，根据编队位置略增至约 5.7 km，出生高度至少比碰撞地形高 500 m。边缘位置会搜索地图内的远处入口，绝不把新敌机放到玩家近旁。入场后至少 4 秒加难度反应时间才允许开火；存活敌机在边缘自行转向返航，不再瞬移到玩家前方。无尽模式第 1–3 波采用简单战术，第 4–7 波普通，第 8 波起困难；装甲、转弯和敌方伤害继续按原十波曲线递增。

## 血量与伤害

玩家、敌机、靶机、敌舰、三架僚机、两关护航航母的基础血量均为 1.20 的两倍；伯克与 052D 的部件 HP 同样翻倍。大黄蜂基础 200 HP、歼-16 250 HP；D-21 / 伯克 / 052D 为 600 / 840 / 780 HP；僚机 270 HP；第二、七关航母分别为 4400 / 4000 HP。难度和关卡装甲倍率仍在此基础上应用一次。

玩家机炮、舰炮、空空、防空与反舰导弹的基础伤害统一减少 **15%**，然后应用原航空技术和本次弹药等级倍率。敌方及僚机火力不变。近防炮继续使用独立防御逻辑，不扣主炮弹药费用。

## 弹药

基地「弹药 / 钱包」可查看和选择弹药；作战 HUD 可循环切换。导弹等级同时适用于空空、防空和反舰武器；机炮等级也适用于舰炮。

| 武器 | 档位 | 相对新基础伤害 | 每次成功开火费用 |
| --- | --- | --- | --- |
| 导弹 | M-I 基础 | ×1 | 免费，无限 |
| 导弹 | M-II 强化 | ×1.4 | 30 银币 / 枚 |
| 导弹 | M-III 精锐 | ×2 | 4 金币 / 枚 |
| 机炮 / 舰炮 | 普通弹 | ×1 | 免费，无限 |
| 机炮 / 舰炮 | 穿甲弹 | ×1.4 | 1 银币 / 发 |
| 机炮 / 舰炮 | 高爆弹 | ×2.2 | 1 金币 / 发 |

例：大黄蜂基础机炮从 24 降至 20.4，普通 / 穿甲 / 高爆弹分别造成 20.4 / 28.56 / 44.88 伤害（未升级）。鱼叉基础弹 238、强化弹 333.2、精锐弹 476。

只有成功创建一发炮弹或导弹才扣费；暂停、未锁定、越界、冷却、过热、舰船武器模块故障、并行防空通道占满都不扣币。余额不足时自动使用免费基础弹，更新选择并提示，不出现负余额。训练固定使用免费基础弹，保留实战弹药偏好。

为满足无限基础弹的玩法，武器使用**虚拟储备**：先消耗原实际挂载和弹舱计数，耗尽后仍可按当前兼容武器发射；付费弹药受余额限制。初始容量、已发射挂载的 3D 隐藏、载荷重量、波间补充上限继续保留，虚拟储备不增加实体挂点或认证挂载。未配置的空空或反舰武器仍不可使用。所有武器保留冷却、锁定、热量和模块限制；取消原「弹药耗尽即失败」。

## 货币与等级

新档或旧版首次迁移获得 1200 银币（旧档按原余额转换）和 25 金币。旧改装点 `credits` 按 1:1 转为 `silver`，`credits` 仅保留兼容镜像；`gold` 独立保存，升级和挂载保留。存档仍为浏览器 `frostline-workshop-v1`，内容版本升至 2；迁移不重复赠币，刷新和重开不返还消费。没有充值或服务器账号，不同浏览器、域名和设备之间不自动同步。

飞机和舰船实战统一结算：

- 银币 = 100 + 击杀 × 60 + min(500, floor(得分 / 20)) + 胜利额外 300 + 战役固定通关奖励。
- XP = 击杀 × 100 + 胜利额外 400。
- 普通实战胜利获得 8 金币；战役第 N 关胜利获得 10 + 2N 金币，另加原 500–2200 的固定银币奖励。
- 无尽模式每完成三波，在本局结算时获得 2 金币。
- 失败有击杀仍结算战斗银币和 XP；训练、无击杀失败、主动退出不发奖励。同一结果页只结算一次。

指挥官共 30 级。第 L 级累计 XP 门槛为 `(L−1)×400 + (L−1)×(L−2)×100`；首次升级需要 400 XP，此后每级需求增加 200。进度条显示本级已获经验、总需求和距离下一级的差额，满级显示 30 级。

四条航空技术仍各有五档、全机型共享，从各机型独立基础值计算。五档依次要求指挥官 **1 / 3 / 5 / 8 / 12 级**，花费 **300 / 700 / 1400 / 2400 / 3800 银币**。金币只用于高级弹药。旧档已购技术不会因新等级门槛被降级。

## 验证

`npm test` 包括经济迁移、等级边界、五种载具的实际导弹命中、炮弹伤害、成功开火扣费、免费储备与反舰航迹回归，以及十张地图边缘的远距出生、分级战术、导弹诱饵和持续飞行无水平瞬移检查。`npm run test:combat` 通过 Chromium 验证实际选择入口、键盘发射与开火、刷新和重开、防重复结算、等级进度及手机横竖屏布局。浏览器中的结算覆盖使用受控战果夹具，完整关卡流程另见 `test:campaign`。
