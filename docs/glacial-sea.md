# 冰原海域（GLACIAL SEA）

第五张作战区域，地图 ID `glacial-sea`。原创场景，参考北极群岛和峡湾的冰川海岸外观，不对应任何实测地点。快速任务和训练可以选择这张地图；战役仍然只使用北大西洋。

## 布局

| 区域 | 内容 |
| --- | --- |
| 中央水道 | 宽约 4.4 km，从 z = 8500 延伸到 z = −10800，全程是深水。玩家出生点、舰队航线和原任务进场路线保持不变。水道里只有薄碎冰和小浮冰，不会挡住舰船。 |
| 东西两岸 | 两座入海冰川（西侧冰崖高 60 m，东侧 54 m），各被两座黑色玄武岩雪山夹住。冰川上游通往两座冰盖山体。 |
| 两侧海域 | 浮冰群、冰山群和崩解碎冰。 |
| 北方 | 约 3.3 km 长、1.9 km 宽的平顶「冰岛」，冰崖高 47 m，作为远方地标；后方是四座 2.2–3.0 km 高的冰盖山脉。 |

共有 139 座实体冰山：27 座手工布置的地标冰山，另有 112 块碎冰由固定随机种子生成，主要分布在冰川前缘和大冰山周围。每位玩家、每档画质、每次加载生成的目录都完全相同。

## 现实参考与游戏近似

| 项目 | 现实参考 | 游戏近似 |
| --- | --- | --- |
| 冰山形态 | 国际冰情巡逻队（IIP）把冰山分为平顶（tabular），以及非平顶的圆顶、尖顶、楔形、船坞形、块状。 | 六种形态全部实现。平顶冰山用折线断裂面加崩解凹口；尖顶冰山有 1–3 个尖峰；船坞形冰山两座冰塔之间夹一条侵蚀槽。 |
| 水下部分 | 冰的密度约 917 kg/m³，海水约 1025 kg/m³，所以冰山大约九成体积在水下。 | 只模拟水上部分。冰崖外沿有 2.5–7 m 的陡峭碰撞裙边，代表水下冰脚；没有隐藏的水下冲角，水下冰脚的青蓝色只是视觉效果。 |
| 冰山尺寸 | 大型平顶冰山的干舷可达数十米；IIP 的小冰块分类为 growler（水面以上不足 1 m）和 bergy bit（1–5 m）。 | 平顶冰山 37–47 m，尖顶冰山最高 112 m。碎冰半径 8–54 m、高 2.6–18 m，比真实 growler 大，以便高速飞行时仍能看清。 |
| 入海冰川 | 入海冰川的崩解冰崖通常高出水面数十米；下游可见横向冰裂隙、中碛、侧碛和波状冰拱（ogive）。 | 冰川纵剖面上凸，冰崖用同一高度场的数米陡坡表示。前缘有冰塔起伏；横向冰裂隙、两条在前缘汇合的中碛和侧碛在着色器中绘制。 |
| 海冰 | 浮冰按密集度区分；还有冰间水道（lead）、碎冰、压力脊和尼罗冰（nilas，很薄的暗色新冰）。 | 由每张地图约 190 m 一格的浓度场驱动：大浮冰（约 86 m 格）可以融合或保留裂缝，公里级水道网把冰群分成巨型浮冰，水道里有碎冰（约 17 m 格），还有压力脊、浮冰边缘的水下青蓝光晕和背光侧阴影，以及尼罗冰。 |
| 海冰与航行 | 非破冰级驱逐舰应避开密集冰区。 | 海冰只是海面着色，没有碰撞，舰船可以穿过薄冰。实体障碍只有冰山、冰川和陆地。 |

## 碰撞与渲染一致

- `world-math.js` 的 `icebergHeight` 用极坐标轮廓加顶面函数定义每座冰山。网格按 400 m 分格建立空间索引，`terrainHeight` 会同时考虑岛屿、建筑和冰山。
- `icebergs.js` 生成径向网格：顶面若干圈，再加贴合碰撞裙边的冰崖。所有冰山合并成 1 次光照绘制和 1 次水下冰脚绘制，网格的每个顶点都落在碰撞面上（测试逐点检查）。
- 冰川用顺着崩解前缘排布的曲线网格。冰崖不需要另外加几何体，地形里的岸线浪花和船只搁浅判定都沿用同一高度场。
- 冰山和冰川共用一个冰材质：顶部是风压雪面；冰崖从上部的粒雪白逐渐过渡到靠近海面的冰川蓝，带层理、融蚀纵槽，水线处有一圈浪蚀湿冰。背光的冰崖有一点体内散射的微光。法线扰动会按像素覆盖面积淡出，远处不会闪烁。

## 性能

| 画质 | 地形与场景三角形 | 绘制调用 |
| --- | --- | --- |
| 标清 | 约 6.2 万 | 16 |
| 高清 | 约 16.8 万 | 16 |
| 超清 | 约 30.0 万 | 16 |

这些数字都在现有测试预算以内（7.5 万 / 18.4 万 / 33 万三角形，30 次绘制）。海冰不增加几何体或绘制调用：

- 标清只做一层浮冰格计算；
- 高清和超清增加公里级水道、碎冰和压力脊；
- 远处像素在像素覆盖面积超过浮冰尺寸后，直接使用期望覆盖率，跳过全部格子搜索。

在云端 SwiftShader 软件渲染中，同一视角下新地图的帧耗时比「极地冰原」多约 15%（标清）到 20%（高清）。这个比例只能作相对参考，不代表实体设备的帧率。

## 验证

- `node --test tests/glacial-sea.test.mjs`：冰山目录固定且不重叠、冰崖连续、全部三档的冰山和冰川顶点都落在碰撞面上、冰川冰崖、海冰水道、海面纹理原地更新、部署图冰山标注。
- `npm run test:glacial`：浏览器中选择地图、飞机出击、驱逐舰舰炮训练，以及手机竖屏和横屏的标清出击。截图保存在 `verification/glacial-sea/`，按仓库规则不提交。
