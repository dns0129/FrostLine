# 暗潮行动：十关海空战役

航母舰队演习时遭遇无识别机群。玩家呼号“苍隼”，与三架自主交战的 K-7 僚机组成四机小队，从紧急迎战、掩护企业号撤退，逐步追查并摧毁“暗潮”无人作战网络。玩家可驾驶现有 F/A-18C 或歼-16，僚机使用已有 K-7 模型；敌方驱逐舰使用已有 110 米 D-21 外形和独立敌军属性。剧情、敌军身份与战斗参数均为游戏设定。

第一关“五波 20 架”指五波合计二十架，每波四架。全战役每关五波，十张不同的实体地图；新增风暴海峡、珊瑚群岛、暮色海湾、黑礁火山海和极夜海盆，其余五张沿用现有地图。新增地图有各自的地形、光照与海色，也可用于快速任务及训练。天气为视觉主题，不额外改变飞行动力学。

## 交战与补给

僚机实际机动、发射机炮和导弹，空中威胁清除后可攻击敌舰；每架僚机每波携带一枚反舰弹。敌方可攻击玩家、僚机与指定护航航母。绿色三角与雷达绿点标记僚机，HUD 显示友机存量。小队所有击落、击沉共同计入关卡战果与战斗奖励；僚机机炮命中不会增加玩家个人命中率。僚机可被击落，关内补给不会复活它们；重新出击和下一关重新编组为四机。

海空目标全部清除才触发波间补给与 4.5 秒间隔。玩家修复 25 HP、补充最多 320 发机炮弹、1000 kg 燃油和 3 枚诱饵，空空及反舰弹按出击时的兼容挂载补满；不增加挂点或初始武器容量。1.21 起已配置武器另有免费无限基础弹储备，耗尽挂载仍可开火，保留锁定、热量和冷却。存活僚机修复 25 HP 并补一枚反舰弹。混合海空关在简报和实际启动入口均检查反舰挂载。没有反舰弹时需返回机库整备。

两关护航中，企业号具有独立耐久（4400 / 4000 HP），与两艘背景护航舰沿真实直线撤离航线移动，不再绕背景巡航圈。驱逐舰和指定攻击机优先攻击航母，命中的实体炮弹、制导导弹会扣减航母 HP。必须清除五波全部敌人且航母存活、抵达出口、玩家在防区内才会获胜。防区半径 6.5 km，连续离区 20 秒、航母被击沉、玩家被击落或超时会失败。玩家返回防区会清零连续离区警告。

每关敌机装甲、转向、伤害逐级增加，导弹发射间隔缩短；敌机和驱逐舰总数不下降。玩家选择的轻松、标准、王牌难度在此基础上生效。后期指挥机获得额外装甲与机动，击毁指挥机不能跳过剩余目标。

## 银币、金币与存档

通关固定奖励合计 **12250 银币**，每次完成关卡都会发放，重玩也会获得。固定奖励叠加战斗银币和 XP，结果界面单独列出“含通关奖励 N 银币”，写入 `frostline-workshop-v1` 的银币余额，可购买引擎、火力、防御、机动四条共享技术路线和中级弹药。每关胜利另获 10 + 关卡编号 × 2 金币，用于高级弹药；旧点数按 1:1 迁移，见 [作战与经济系统](combat-economy.md)。失败仍按原规则结算战斗奖励，不发本关通关奖励；同一结果界面只能结算一次。

战役顺序进度、星级和最高分存入独立的 `frostline-campaign-v2`（version 2），防止原三章北境航线存档跳过新剧情。旧存档保留在原键下，航空升级、挂载、快速任务地图设置与成绩继续使用原存档。新战役不会覆盖快速任务的地图偏好。通关第 1–9 关后按钮打开下一关四页简报；第 10 关显示战役完成。

## 验证

运行 `npm run check`、`npm test`、`python3 -m unittest discover -s tests -p 'test_*.py'`、`npm run prepare`。`npm run test:campaign` 使用 Chromium 实际 WebGL，检查十关简报、地图与实体首波、四机编队、真实锁定后键盘 F 发射并命中、航母击沉失败与重试、暂停、顺序解锁、逐关奖励、防重复结算、升级购买及存档恢复，以及三种手机横竖屏视口。

自动化中的完整十关胜利使用显式清敌与撤离时间测试夹具，验证规则和流程；不代表十关完整人工游玩或实体设备帧率验收。地图数值测试另覆盖十张地图的三档几何、碰撞、舰队航道与快速任务出生安全。
