# 基地与分页作战简报

游戏以现有机库／海军基地作为主页。选载具、挂载和武器战备后，点击「开始游戏」，依次进入模式选择、剧本／任务选择和四页全屏简报：战斗简介、剧本细节、部署情况、任务目标。只有目标页的「确认出击」才会开始模拟；阅读和返回不会消耗弹药、推进任务时间或改写战役进度。

快速任务包括破晓拦截、无尽巡猎和海峡歼敌；训练模式包括飞行／航行训练及反舰／舰炮训练，支持十张地图。战役使用“暗潮行动”十关，每关指定不同地图，按顺序解锁；通关额外奖励银币与金币。当前战役限战机，海军基地的战役选项有明确说明；未解锁的章节可阅读全部简报，但不能出击。飞机未挂载反舰导弹时，对海任务及含水面目标的战役关可查看，出击按钮会提示返回整备。

简报顶部页签、底部前后按钮可切页，页签支持左右方向键与 Home／End。Escape 逐层返回。最终页可进入机库或海军基地整备，关闭整备面板后回到原任务的最终页，更新所选挂载与出击条件。战役结算的下一章按钮先打开下一章简报，避免直接进入下一场战斗。快速任务地图偏好保留在原设置存档，不会被战役固定地图覆盖。

`mission-briefing.js` 直接读取 `campaign.js` 的剧情、波次、目标、时限和防区规则，不依赖 DOM。`sortie-flow.js` 负责全屏导航、章节锁定提示与地图 SVG，`sortie-flow.css` 单独控制桌面、手机竖屏和横屏布局。原有战斗启动与模拟仍由 `app.js` 和 `simulation.js` 负责。

部署图读取所选地图的岛屿参数、关卡初始出生点、护航舰队初始位置和防区半径。敌方标记为部署示意，不提供实时坐标；两关护航中的企业号参与受击和撤离判定；其他背景舰队仍为场景参照。部署图标记三架僚机与混合海空目标，简报列出通关银币。图上标注与图例同时使用形状和颜色。

`npm run test:sortie` 使用 Chromium 的实际 WebGL 渲染，验证基地入口、模式和地图选择、锁定章节、四页阅读、最终确认、整备返回、战役下一章、两型舰船及手机横竖屏。首章通关采用显式模拟测试夹具以验证解锁和下一章入口，不代表完整人工通关。手机验证为视口与触控模拟。
